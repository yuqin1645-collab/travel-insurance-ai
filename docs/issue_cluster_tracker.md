- 同时 `last_planned_dep_utc` 使用了 `_dep_iana`（首段AMS）而非末段CAN的时区
- 修复1：`_try_parse_local()` 调整为 `tz_hint` 优先于 `fallback_iana`（tz_hint 是AI直接从材料提取的时区，更可靠）
- 修复2：联程改签场景下末段时间解析使用末段机场IANA（从 `alternate_local.alt_dep_iata/alt_arr_iata` 解析）而非首段 `_dep_iana/_arr_iana`
