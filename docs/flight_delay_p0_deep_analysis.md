#### 样例1：a0nC800000ODl1hIAD — 中转接驳国内段未识别

**ForceID**: a0nC800000ODl1hIAD
**BenefitName**: 航班延误
**AI结果**: 通过，延误9小时，赔付300元
**人工结果**: 拒绝
**人工备注**: "会员权益仅保障国际直飞航班延误，本次申请取消航班MU6531为国内段航班，且依据权益免除责任（权益人因乘坐前次航班的任何延误，导致其未能准时搭乘到原预定的接驳航班所造成的航班中转延误），本次申请未达赔付标准"

**代码逻辑分析**:
- `hardcheck.py` 的 `domestic_flight_check`: 检测纯国内航班（出发地和目的地都在CN）。MU6531如果是HKG→KMG（香港→昆明），香港不在CN country_code中（HK独立），所以未被检测为纯国内
- `missed_connection_check`: 未触发中转接驳免责。原因：Vision可能未提取到"missed connection"关键词，且AI解析的`itinerary`中`mentions_missed_connection`为false
- 最终hardcheck无拦截 → 进入AI审核 → AI计算延误9小时 → 通过

**根因链条**:
1. 国际联程航班中，国内段（MU6531）取消/延误
2. Vision未识别到"中转接驳"关键词 → `mentions_missed_connection=false`
3. hardcheck的`missed_connection_check`未触发
4. AI独立计算延误 → 通过
5. 人工根据业务规则（国内段+中转接驳）拒绝

**问题定位**: 代码层面有两个问题：
- **Bug**: 中转接驳检测未覆盖所有场景，部分案件未触发
- **业务逻辑缺口**: 国际联程的国内段延误/取消，即使不满足中转接驳条件，也可能不在保障范围内（"会员权益仅保障国际直飞航班延误"）

**修复建议**: 需要业务确认"国际联程国内段"的处理规则，同时强化中转接驳检测

#### 样例2：a0nC800000IbiPVIAZ — 延误计算口径分歧

**ForceID**: a0nC800000IbiPVIAZ
**BenefitName**: 航班延误
**AI结果**: 通过，延误12小时32分，赔付600元
**人工结果**: 拒绝
**人工备注**: "2/27航班SK4095起飞延误1小时58分钟，到达延误1小时34分钟，未达到起赔标准5小时，且依据权益免除责任（中转接驳延误）"

**代码逻辑分析**:
- AI计算的12h32m = 改签航班时间 - 原航班计划时间（口径2）
- 人工计算的1h58m = 原航班实际起飞时间 - 原航班计划起飞时间
- **关键分歧**：当有改签航班时，延误时长应该用哪个口径？
  - AI使用"计划→改签实际"（旅客实际经历的延误）
  - 人工使用"原航班计划→原航班实际"（原航班自身的延误程度）

**根因链条**:
1. SK4095延误1h58m（未达5小时），但有改签航班
2. AI用改签航班计算延误 → 12h32m → 通过
3. 人工用原航班自身延误 → 1h58m → 未达起赔 → 拒绝
4. 同时人工还应用了中转接驳免责

**问题定位**: **业务逻辑分歧，非代码bug**
- 代码的延误计算逻辑（计划→改签实际）在"改签"场景下是合理的
- 但人工的审核标准是：原航班延误必须≥5小时才能赔，改签不算
- 这涉及保险条款中"延误"的定义：是"原航班延误"还是"旅客最终到达延误"

**修复建议**: 必须与业务确认：
1. 航班延误的起赔门槛（5小时）是针对原航班自身延误，还是旅客最终到达延误？
2. 如果原航班延误<5小时但改签后总延误>5小时，是否应该赔付？
3. 中转接驳免责的触发条件是什么？是否需要原航班延误也达到一定门槛？

**与业务沟通要点**:
- ForceID: a0nC800000IbiPVIAZ
- 原航班: SK4095 (2/27)
- AI逻辑: 用改签航班计算延误12h32m（旅客实际经历的延误）
- 人工逻辑: 原航班SK4095仅延误1h58m，未达5小时起赔标准
- 问题: 条款中"延误5小时"的定义是什么？原航班延误？还是旅客最终到达延误？

## 四、P2 分析（243件）

### 4.1 P2 是最大问题簇

P2占28.5%，是影响一致率的最大因素。243个案件中：
- 225件人工通过
- 18件人工需补齐资料

### 4.2 P2 推断原因分布

基于人工备注和AI审核结果的交叉分析：

| 原因 | 推断数量 | 说明 |
|------|---------|------|
| 延误未达门槛（计算偏短） | ~100+ | 最大的子类别，与P0的延误计算分歧同源 |
| 中转接驳免责误判 | ~40 | hardcheck或AI审核层误判 |
| 纯国内航班误判 | ~30 | Vision只识别国内航段 |
| 重复索赔误判 | ~20 | 重复索赔判定偏严 |
| 保单有效期误判 | ~10 | 有效期判定偏严 |
| 其他 | ~40 | 需逐案分析 |

### 4.3 关键洞察

P0和P2的**延误计算口径分歧**是同一个根本问题的两个方向：
- P0: AI用改签计算 > 5小时 → AI通过，但人工用原航班计算 < 5小时 → 人工拒绝
- P2: AI用改签计算 > 5小时但hardcheck拦截了 → AI拒绝，但人工可能认为应该通过

## 五、修复优先级

### 第一优先级：中转接驳检测强化（影响3件P0 + ~40件P2）

**问题**: `missed_connection_check` 未覆盖所有中转接驳场景
**修复**: 强化关键词匹配 + 增加业务规则兜底

### 第二优先级：延误计算口径确认（影响2件P0 + ~100件P2）

**问题**: 改签场景下，延误计算用改签航班 vs 原航班
**修复**: **需要业务确认条款定义**，非纯代码问题

### 第三优先级：材料门禁放宽（影响~22件P1）

**问题**: 出入境记录等兜底逻辑不够宽
**修复**: 已有经验，可快速实施

## 六、业务逻辑问题清单

以下是**非代码/prompt问题，而是业务规则不明确**的案例，需要与业务方沟通：

### BL-001: 国际联程国内段的保障范围

**ForceID**: a0nC800000ODl1hIAD
**代码逻辑**: 如果Vision未识别到"中转接驳"关键词，且机场country_code判断非纯国内，则放行
**人工结果**: 拒绝 — "会员权益仅保障国际直飞航班延误，本次申请取消航班MU6531为国内段航班"
**业务问题**:
1. 国际联程航班中，如果国内段（如HKG→KMG）取消/延误，是否在保障范围内？
2. "国际直飞航班"的定义是什么？是否包含联程航班中的国内段？
3. 如果包含，是否需要满足什么额外条件？

**建议沟通话术**:
> 关于航班延误权益，我们遇到一个场景：旅客购买了国际联程机票（如 上海→香港→昆明），其中香港→昆明段（MU6531，国内段）因故取消。AI审核认为这是国际行程的一部分予以通过，但人工审核以"会员权益仅保障国际直飞航班延误"为由拒绝。
>
> 请确认：
> 1. 国际联程中的国内段航班延误/取消，是否在保障范围内？
> 2. 如果是，起赔门槛（5小时）如何计算？
> 3. 如果不在，AI应如何识别这类场景？

### BL-002: 改签场景的延误定义

**ForceID**: a0nC800000IbiPVIAZ, a0nC800000IViDhIAL, a0nC800000JIVDjIAP
**代码逻辑**: 改签场景下，延误 = 改签航班实际时间 - 原航班计划时间（旅客最终经历的总延误）
**人工逻辑**: 延误 = 原航班实际时间 - 原航班计划时间（原航班自身的延误程度）
**业务问题**:
1. 航班延误的起赔门槛（5小时）是针对**原航班自身**的延误，还是**旅客最终到达**的总延误？
2. 举例：原航班延误1小时，但改签后旅客最终晚到12小时，是否应该赔付？
3. 如果应该赔付，赔付标准是按原航班延误还是改签后总延误？

**建议沟通话术**:
> 关于改签场景的延误计算，我们发现AI和人工的标准不一致：
>
> 以案件 IbiPVIAZ 为例：
> - 原航班 SK4095 起飞延误1小时58分
> - 航司安排了改签航班，但改签航班比原计划晚12小时32分
> - AI认为延误12小时32分（超过了5小时门槛），应该赔付
> - 人工认为原航班只延误了1小时58分（未达5小时），不予赔付
>
> 请确认：
> 1. 条款中的"航班延误5小时"是指原航班自身延误，还是旅客最终到达延误？
> 2. 如果原航班延误<5小时但改签后总延误>5小时，是否应该赔付？

### BL-003: 中转接驳免责的触发条件

**ForceID**: a0nC800000IbiPVIAZ, a0nC800000IViDhIAL, a0nC800000JIVDjIAP, a0nC800000ODl1hIAD
**代码逻辑**: 当检测到"missed connection"关键词或联程+延误原因暗示时，触发中转接驳免责
**人工逻辑**: 部分案件人工引用了中转接驳免责，但AI未检测到相关关键词
**业务问题**:
1. 中转接驳免责的完整触发条件是什么？
2. 是否只要旅客有联程+改签就触发？还是需要满足原航班延误达到一定门槛？
3. 人工备注中"权益人因乘坐前次航班的任何延误..."这段免责条款的准确适用范围是什么？

**建议沟通话术**:
> 关于中转接驳免责条款，我们需要明确其适用范围：
>
> 条款原文提到："权益人因乘坐前次航班的任何延误，导致其未能准时搭乘到原预定的接驳航班所造成的航班中转延误"
>
> 请确认：
> 1. 只要旅客有联程航班且发生了改签/误机，就触发此免责吗？
> 2. 还是需要前序航班延误达到一定时长（如1小时以上）才触发？
> 3. 如果前序航班延误很短（如15分钟），但旅客仍然错过了后续接驳航班，是否触发此免责？
